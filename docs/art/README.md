# Art References

This folder stores reference art, screenshots, visual audits, and generated-asset evidence.

## Layout

- `concepts/`: canonical concept images and sheets.
- `phase-0/`, `phase-2/`, `phase-5/`, `phase-5.1/`, `phase-5.2/`: phase-specific screenshots, audits, comparisons, and visual notes.
- `perspective-overhaul/`: screenshots and comparison notes for the perspective overhaul track.
- `visual-overhaul/`: detailed visual-overhaul evidence, prompts, metrics, and contact sheets.
