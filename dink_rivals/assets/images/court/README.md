Court asset notes
=================

`court_surface_texture_generated.png` is normalized from the generated texture
source archived at:

- `docs/art/visual-overhaul/contact-sheets/court-surface-texture-generated.png`
- `docs/art/visual-overhaul/prompts/court-surface-texture-generated.md`

The runtime texture is line-free and rendered as a low-opacity clipped overlay
inside `CourtComponent`. Court geometry, white lines, kitchen zones, hitboxes,
and physics remain controlled by code.
